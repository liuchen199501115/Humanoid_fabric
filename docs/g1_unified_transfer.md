# 全身参考承重转移与首次抬脚

## 范围

这是从 `walk1_g1.pkl` 首次换脚前的停止状态开始，验证“双支撑承重转移 → 左脚支撑 → 右脚抬起”的独立诊断。源帧在首次起步后保持，尚未接入原始步幅、落地或连续左右换脚。不能将本诊断通过解释为完整 PKL 跟踪通过。

```bash
cd /home/sky/Humanoid_fabric
bash examples/run_lafan_transfer.sh --show-isaac-window
```

默认运行 12 秒仿真，输出 `acc_data/lafan_unified_transfer.npz` 和 `.transfer.json`。诊断参数 `--unified-transfer-test` 与 `--until-motion-end` 互斥。完整跟踪入口仍是 `run_lafan_tracking.sh`，该入口没有自动启用本诊断。

## 实现

`src/fabrics_sim/reference/contact_transfer.py` 在管理器进入 `PREPARE_STEP` 且参考停止后接管参考生成：

1. 保存当前全身参考、实测双足接触姿态和下一个支撑脚。
2. 用 2 秒五次曲线转移重心至支撑脚内；重心高度降低 2 cm，为腿部伸展留出余量；双脚参考平滑对齐实测接触姿态。
3. 保留源根姿态和上身关节，联合求解根位置及 12 个腿部关节。位置求解受 URDF 关节限位约束；通过同一个雅可比求广义速度、加速度，并计入 `Jdot*v`。
4. 所有关节、骨盆、双足、双手、重心和角动量目标都由这一套 `WholeBodyReference(q,v,a)` 派生。
5. 过渡完成后，管理器继续使用实测承重比例、稳定性和持续确认时间，允许切换接触模式。没有强制释放负重脚，也没有重置机器人状态。
6. 实际允许切换后，用 1 秒抬高摆动脚 4 cm，保持同一重心和支撑脚目标。诊断阶段保持源帧，并持续检查支撑接触。

开始前抽样检查转移和抬脚路径的几何可达性；每个控制步重新检查关节限位。这个检查不构成连续路径或动力学可行性的证明，物理执行仍由 QP 与仿真验证。

## 验收

- QP 和扭矩按仿真 500 Hz 更新。
- 切换后至少运行 3 秒。
- 最后 1 秒保持同一单脚支撑；支撑力至少 100 N，摆动脚力小于 10 N。
- 摆动脚所有足底角点离地至少 2 cm，重心跟踪误差不超过 3 cm。
- 原有 QP、执行器、关节限位和全程控制器检查仍必须通过。
- 原始 PKL 的姿态误差及源帧记录继续保留，诊断报告明确标记 `full_pkl_tracking: false`。

47 项单元回归覆盖全身参考一致性、双侧几何求解、运动导数、提前释放拒绝、源姿态保护、原有管理器和验收失败判定。
