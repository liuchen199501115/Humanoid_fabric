# 基于 Kinodynamic Fabrics 的 G1 人形机器人动捕轨迹 Tracking 方案与系统分析

## 1. 概述与设计背景

本文档针对 Unitree G1 人形机器人使用 GMR 重定向动捕数据 (`.pkl` 文件) 进行全身运动追踪（Whole-Body Tracking）的控制架构进行深入分析。

传统基于任务空间（Task Space）加速度解算、零空间投影（Null-space Projection）及硬约束二次规划（QP）的全身控制（WBC）流程，在直接追踪纯运动学动捕轨迹时极易引发 **QP 无解崩溃 (Infeasible QP)**、**碰撞冲量跳变** 以及 **动量/平衡失控**。

本方案引入 **Kinodynamic Fabrics (动力学纤维)** 框架，将多任务空间追踪转化为黎曼流形（Riemannian Manifold）上的几何微分方程系统，通过微分几何的 **Pullback (拉回)** 与 **Summation (求和)** 操作，实现了解析式、高频、连续且物理可行的全身动力学控制指令生成。

## 2. 整体控制系统流程架构 (Control Pipeline)

```
 [ .pkl (GMR Retargeted Target) ]
                 │
                 ▼
 [ Phase 1: Task Space Fabrics Setup ]
   ├── Task 1: Pelvis Tracking (Position & Orientation)
   ├── Task 2: End-Effectors (Feet & Hands Tracking)
   └── Task 3: Joint Limits & Collision Avoidance
                 │
                 ▼
 [ Phase 2: Pullback & Riemannian Summation ]
   ├── Riemannian Metrics Calculation: M_i(q)
   ├── Geometry Pullback via Jacobians: J_i^T * M_i * J_i
   └── Composed Acceleration Output: q_ddot
                 │
                 ▼
 [ Phase 3: Dynamics & Contact Consistency ]
   ├── Inverse Dynamics (RNEA): M(q)q_ddot + C q_dot + G = tau + J_c^T * F
   └── Friction Cone & Contact Force Solver -> Feedforward Torque (tau_ff)
                 │
                 ▼
 [ Phase 4: Integration & MIT Mode Command Generation ]
   ├── Numerical Integration: q_ddot -> q_dot_des -> q_des
   └── MIT Command Assembly: tau_cmd = Kp*(q_des - q) + Kd*(q_dot_des - q_dot) + tau_ff
                 │
                 ▼
 [ Phase 5: MuJoCo Physics Engine / Hardware Execution (1kHz) ]
```

## 3. 核心控制模块详细展开

### 3.1 任务空间纤维建模 (Task-Space Fabrics Formulation)
每个运动任务 $i$ 在各自的任务空间 $x_i$ 中被建模为一个**二阶强制光谱半喷泉（Forced Spectral Semi-Spray）**方程：

$$M_i(x_i) \ddot{x}_i + f_i(x_i, \dot{x}_i) = -\nabla_{x_i}\psi_i(x_i) - D_i(x_i, \dot{x}_i)\dot{x}_i$$

* **Pelvis 姿态任务**：设置势能吸引子 $\psi_{pelvis}$，维持 G1 的质心高度与躯干基座姿态。
* **双脚末端与接触**：在支撑期设定高阻尼，在摆动期设定轨迹追踪势能场。
* **双手末端**：根据 `.pkl` 数据实时更新三维空间目标点。

### 3.2 黎曼几何拉回与求和 (Pullback & Summation)
利用几何拉回将分散的任务映射回关节空间 $q$：

1. **度量拉回 (Metric Pullback)**：
   $$\tilde{M}_i(q) = J_i^T(q) M_i(x_i) J_i(q)$$
2. **复合求和 (Summation)**：
   通过黎曼流形自然复合，彻底避免传统 QP 的逻辑死锁与无解报错，解析计算出连续平滑的关节空间加速度 $\ddot{q}$。

### 3.3 逆动力学与接触解算 (Dynamics & Torque Generation)
通过递归牛顿-欧拉算法（RNEA）与接触雅可比 $J_c$ 计算前馈力矩：

$$\tau_{ff} = M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) - J_c^T F_{contact}$$

其中 $F_{contact}$ 需确保满足地面摩擦锥（Friction Cone）约束。

## 4. 可行性评估与对比分析

| 评估维度 | 传统零空间投影 + 加速度 QP 方案 | Kinodynamic Fabrics 方案 |
| :--- | :--- | :--- |
| **求解稳定性** | 易产生 Infeasible 无解崩溃 | **绝对不会崩溃**（黎曼流形解析解/平滑凸优化） |
| **轨迹平滑度** | 容易发生受限加速度突变 | **内禀连续平滑**（二阶微分方程吸引子） |
| **计算频率** | 受限于多约束 QP 求解速度 | **极高**（可稳定跑在 1kHz 以上） |
| **简化模型依赖**| 通常强依赖 LIPM / ZMP | **不依赖简化模型**（基于刚体动力学与几何流形） |
| **积分稳定性** | 易发生严重二次积分漂移 | **漂移可控**（加速度连续性大幅衰减累积误差） |

## 5. 纯仿真 (MuJoCo) 落地关键配置要点

为保证在 MuJoCo 仿真中流畅实现，需在工程实践中注意以下要点：

1. **初始姿态严格对齐**：
   仿真启动第一帧，G1 的双脚足底必须与地面严格贴合（避免 Penetration 产生的巨大冲击排斥力或悬空跌落）。
2. **关节软限位障壁函数 (Barrier Functions)**：
   在 Kinodynamic Fabrics 的势能函数中加入形如 $-\ln(q_{max} - q)$ 的障壁项，确保在追逐动捕极限动作时不会硬撞 MuJoCo 的关节 Limit。
3. **仿真步长与控制频率配合**：
   * **控制周期**：$1\text{ms}$ ($1000\text{Hz}$)
   * **MuJoCo 物理步长**：$0.25\text{ms} \sim 0.5\text{ms}$ (每控制步跑 2~4 个 Sub-steps)，提高数值积分与接触求解稳定性。
4. **MIT 模式增益调优建议**：
   * $K_p \in [40, 100]$ N·m/rad
   * $K_d \in [1, 5]$ N·m·s/rad
   * 依托稳定的前馈力矩 $\tau_{ff}$，通常无需设置过高的 $K_p$ 即可获得极佳的追踪精度。
